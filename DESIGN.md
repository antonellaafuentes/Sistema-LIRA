# DESIGN SYSTEM — Sistema LIRA

## 1. Intención y Tono de la Marca
- **Propósito:** Plataforma segura, empática y clara para la prevención y concientización sobre conductas de riesgo y redes de asistencia.
- **Tono Visual:** Cálido, profesional, sobrio y accesible. No debe sentirse clínico ni intimidante, ni caer en clichés gráficos estridentes.
- **Modo:** **Read / Operate** (Claridad inmediata, comprensión sin fricción cognitiva y acceso rápido a soporte).

## 2. Paleta de Colores
- **Fondo Primario:** `#F8FAFC` (Slate-50, blanco suave que reduce la fatiga visual).
- **Superficie de Tarjetas:** `#FFFFFF` con sutil borde `#E2E8F0` y elevación suave (`box-shadow: 0 2px 8px rgba(0,0,0,0.04)`).
- **Texto Principal:** `#1E293B` (Slate-800, contraste óptimo WCAG AAA).
- **Texto Secundario:** `#64748B` (Slate-500).
- **Acento Principal (Identidad):** `#EAD2A8` (Indigo-700, confianza, serenidad).
- **Acento Salud / Esperanza:** `#0F766E` (Teal-700, para contactos y soporte positivo).
- **Alerta / Precaución:** `#C2410C` (Orange-700) y `#DC2626` (Red-600 para emergencias inmediatas).

## 3. Tipografía y Jerarquía
- **Fuente Principal:** Inter / Segoe UI / System Sans-Serif.
- **H1 (Títulos Principales):** 2rem (32px), `font-weight: 700`, interlineado 1.25.
- **H2 (Secciones):** 1.4rem (22px), `font-weight: 600`.
- **Cuerpo:** 1rem (16px), `font-weight: 400`, interlineado 1.6 para máxima legibilidad.
- **Microcopy / Badges:** 0.8rem (13px), `font-weight: 600`, espaciado de letras sutil.

## 4. Componentes y Reglas Visuales
- **Tarjetas:** Bordes redondeados de 12px, padding uniforme (1.25rem).
- **Badges de Categoría:** Color de fondo semitransparente según el tipo de alerta con texto contrastado.
- **Banner de Emergencia:** Visible pero respetuoso, con botón de llamada directa.
